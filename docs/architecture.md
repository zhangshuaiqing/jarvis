## 2. 交互通道

### 2.1 语音

```
麦克风 ──▶ VAD (本地, webrtcvad/silero) ──▶ Whisper API ──▶ 文字
                                                                  │
音箱 ◀── TTS (edge-tts / OpenAI TTS) ◀────────── 回复 ◀──────────┘
```

- 唤醒词：Porcupine / openWakeWord（本地，不耗 GPU）
- VAD：webrtcvad（轻量）
- STT：云端 Whisper API（DeepSeek 或 OpenAI 兼容）
- TTS：edge-tts（免费、中文自然）

### 2.2 App/Web

| 方案 | 适用场景 |
|---|---|
| Telegram Bot | Phase 1 首选 — 零开发，多端推送，Hermes 原生支持 |
| PWA | 后期 — 把 Telegram/web 包成独立 App |
| HA Lovelace | 可选 — 在智能家居面板嵌入对话 |

### 2.3 CLI

现状保持，Hermes Agent 终端交互。

## 3. 人格设计

### 3.1 核心定位

- 伙伴型，非纯工具型
- 有主见：可以提出不同意见，但尊重最终决定
- 主动但不聒噪：只在重要事件时主动推送
- 语言：中文为主，偶尔来点钢铁侠式的幽默

### 3.2 实现方式

通过 Hermes 的 `persona` 文件定义，配合 `memory` 维护长期关系认知。

## 4. 记忆系统

### 4.1 三层记忆

| 层 | 时间跨度 | 实现 |
|---|---|---|
| 短期 (工作记忆) | 当前会话 | Hermes 上下文窗口 |
| 中期 (会话记忆) | 跨会话 | session_search |
| 长期 (事实记忆) | 永久 | Hermes memory + 向量数据库 (Chroma/FAISS) |

### 4.2 向量检索

长期记忆需要语义检索而非关键词匹配。方案：Chroma（轻量，Python 原生，不用外挂数据库）。

```
用户偏好/事件 ──▶ embedding (DeepSeek API) ──▶ Chroma ──▶ 检索 ──▶ 注入上下文
```

## 5. 主动引擎

### 5.1 定时主动

通过 Hermes `cronjob` 实现：

- 早上 8:00：今日天气 + 日程摘要
- 晚上 10:00：明日提醒
- 每小时：机器人状态巡检（以后接入 Telos 后）

### 5.2 事件驱动主动

通过 Home Assistant webhook + Hermes 触发：

- 主人回家 → "欢迎回来，已按你的习惯开灯到暖色"
- 传感器异常 → "厨房温湿度传感器离线，需要检查"
- 机器人异常 → 即时告警（以后）

## 6. 技能体系

| 技能 | 依赖 | 优先级 |
|---|---|---|
| Jarvis 人格对话 | persona + memory | P1 |
| 智能家居控制 | HA API | P1 |
| 天气查询 | wttr.in | P2 |
| 日程管理 | Google Calendar / CalDAV | P2 |
| 机器人控制 | Telos ROS2 | P3 (等 ROS2 就绪) |
| 邮件摘要 | IMAP | P3 |

---

## 7. 安全与隐私

- 语音只在检测到唤醒词后才上传云端
- 长期记忆本地存储（Chroma/JSON）
- 敏感操作需确认（"是否执行开门操作？"）
- Tailscale 组网，不暴露公网端口
